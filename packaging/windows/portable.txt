DreamLab PDF portable mode

While this file sits next to dreamlab-pdf.exe, DreamLab PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the DreamLab PDF-Data folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move DreamLab PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\DreamLab PDF and
%LOCALAPPDATA%\DreamLab PDF) instead. If DreamLab PDF-Data can't be written (for example on a read-only
drive), DreamLab PDF says so and uses the per-user folders instead.
